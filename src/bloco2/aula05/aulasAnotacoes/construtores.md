ANOTAÇÕES DE JAVASCRIPT / JAVA: REFERÊNCIAS E CONSTRUTORES1. Como a Memória Funciona (Variáveis vs. Objetos)O new cria o objeto: Quando você faz new Aluno(), o sistema reserva um espaço real na memória (Heap) para aquele objeto.Variáveis guardam Endereços: Uma variável como Aluno a não carrega o objeto dentro dela. Ela guarda apenas uma referência (o "endereço" ou "ponteiro") de onde o objeto está na memória.Cópia de Referência (Aluno b = a;): Esta linha não duplica o objeto. Ela apenas cria uma segunda variável (b) apontando para o mesmíssimo endereço de a. Se você alterar um atributo por b, a mudança aparecerá ao olhar por a.O que é o null? Significa que a variável existe, mas está "em branco" (não aponta para endereço nenhum). Tentar acessar algo nela gera o erro NullPointerException.2. O papel dos ConstrutoresO construtor é um método especial executado exatamente no momento do new. Ele serve para garantir que o objeto "nasça pronto" e com todos os dados obrigatórios preenchidos.Sem construtor no código: O Java cria um construtor padrão invisível nos bastidores (public Aluno() { }). O objeto nasce com os atributos vazios (null), obrigando você a preencher linha por linha depois.Com construtor criado por você: O construtor invisível deixa de existir. O sistema passa a barrar a criação de objetos incompletos direto na compilação.3. Entendendo a Sintaxe do Construtorjavapublic class Aluno {
String nome; // <-- ATRIBUTO (A gaveta definitiva do objeto)

    // CONSTRUTOR: Tem o mesmo nome da classe e não tem retorno
    public Aluno(String nome) { // <-- PARÂMETRO (O dado temporário que veio de fora)
        this.nome = nome; 
    }
}
Use o código com cuidado.A linha do topo (public Aluno(String nome)): É ela quem obriga o programador a enviar o dado na hora de dar o new Aluno("Ana").O uso do this: Serve para resolver a ambiguidade quando o parâmetro e o atributo têm o mesmo nome.this.nome significa: "O meu atributo (a gaveta deste objeto)".= nome significa: "Recebe o valor temporário que acabou de chegar pelos parênteses".4. Arrays de ObjetosCriar um array de objetos (Aluno[] turma = new Aluno[3];) não cria os objetos automaticamente.Essa linha apenas cria uma estrutura com espaços vazios (null) capazes de guardar referências (setas).Você ainda precisa dar new Aluno(...) para cada uma das posições do array (turma[0], turma[1], etc.) para criar os objetos reais na memória.
